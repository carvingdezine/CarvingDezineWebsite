06 — Voice & Tone
HOW WE SPEAK
✓ Do say
  • Short, declarative sentences. Every word earns its place.
  • Confident, never arrogant. Precision without coldness.
  • Lead with the work, not the credentials.
  • "We carve meaning into design." — active, visual language.
  • Specificity over superlatives. Show, don't tell.
  • Write like a craftsperson — deliberate, skilled, considered.
✗ Avoid
  • "Passionate", "innovative", "disrupting" — hollow buzzwords.
  • Exclamation marks in professional contexts!!
  • Overly casual language that undermines expertise.
  • Lengthy paragraphs when a sentence will do.
  • Vague claims: "We create amazing designs" → meaningless.
  • Emoji in brand copy (only in community/casual social).

07 — Motion & Animation
IN MOTION
Ease: Expressive
cubic-bezier(0.19, 1, 0.22, 1) — Fast in, slow settle. Use for content reveals and page transitions.
Ease: Sharp
cubic-bezier(0.77, 0, 0.175, 1) — Snappy, mechanical. Use for UI state changes and menu open/close.
Duration Scale
Micro: 150ms · Component: 300ms · Page: 650–950ms · Loader: Up to 1200ms. Never animate beyond 1.2s.
Interaction patterns — reusable, documented in this file
Scroll Reveal
Elements fade & slide into place the first time they enter the viewport. Driven by a single IntersectionObserver that toggles an .in class — no per-element JS needed.
.rv.rv-up.rv-left.rv-right.rv-scale.rv-children
Scramble Text
Headings decode from random characters into their final text on scroll-in, via GSAP's ScrambleTextPlugin. Falls back to plain static text if motion is reduced or the libraries fail to load.
CARVE MEANING
data-scramblegsap.registerPlugin(ScrambleTextPlugin)
Parallax Depth
Purely decorative elements drift a few pixels against the scroll — background moves opposite the text — for a subtle sense of depth. Never applied to primary headings, which stay fixed for readability.
Scroll inside this box
.parallax-slow.parallax-med
Factor applied per scroll frame via requestAnimationFrame, based on distance from viewport center.
Floating Scroll Controls
A back-to-top button that fades in after ~60% of a viewport height, plus a scroll down/up toggle that flips direction near the bottom of the page. Both live bottom-right on this document right now.
#cd-top-btn#cd-scroll-btn
Live example: bottom-right of this page.
Particle Network
A canvas of drifting nodes that link when close together, repelled and re-attracted by the cursor — used as the cover's background. Density scales with canvas area; pauses automatically when off-screen to save GPU. Move your cursor over the box below.
Move cursor here
#hero-canvasCD_createParticleNetwork(canvas, opts)
Live example: this page's cover, at the very top.
Hover Sound
Every button, tag, card, and heading plays a short synthesized tone on hover — pentatonic notes that cycle each time, so nothing repeats twice in a row. Muted until the sound toggle (top right) is switched on.
window._hoverSound.play('default'|'link'|'big')
Also drives a soft cursor-tracking tone while moving over the cover's particle network above.
Ambient Pad
A quiet, fixed-volume background drone that starts on the first click or key press anywhere on the page (browsers block audio before a gesture), and stops instantly with the sound toggle.
window._ambientPad.start().stop()
The source page loops a recorded piano track here; that audio file wasn't supplied, so this is a synthesized substitute (four soft detuned sine tones) — swap in a real Audio() loop later using the same start()/stop() interface.
All seven patterns automatically disable themselves for visitors with "reduce motion" set at the OS level (sound is separately opt-in via the toggle, off by default until a gesture), and work identically in light and dark mode — they're built on the same CSS variables as everything else in this document. Full source for each is inline in this file's <style> and <script> blocks, ready to copy into any other project.
