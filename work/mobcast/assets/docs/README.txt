DOCUMENTS (downloads)
=====================
Files linked from the pages for visitors to download. Drop the real file into this folder (assets/docs/)
with the exact name below. Until the file is added, the link opens a "file not found" page, so add it
before the site goes live. No code change needed. Use PDF, and keep each file under about 5 MB.

SECURITY PAGE (security.html)
  Mobcast-Security-Overview.pdf
      Linked from two places: the "Download security overview" button in the hero, and the
      "Download the PDF" button in the "For your security team" section.
      Content per client brief: data residency (India), encryption at rest and in transit, role-based access,
      audit logs, 99.9% uptime SLA, certifications (SOC 2 Type II, ISO 27001, GDPR).
      Source: the client's "Mobcast-Security-Overview.pdf" (section 5.6 of the content structure document).

  When one of these pages is built, add the file here and link it with  href="assets/docs/<file name>" download.

NAMING
  Keep the exact file names above (case sensitive, no spaces). To use a different name, change the href in the page too.
