CLIENT LOGOS
============
52 PNGs from the client's Client_Logo.zip, named by slug (e.g. kotak-mahindra-bank.png).
Order and paging (4 x 2, 7 pages) are set in build/logos_block.py (PAGES list).
Replace a file with the same name to update a logo.
Notes: "smile.png" came from "Shree Maruti.png". Religare has no logo, so it shows a text tile.
Emami was supplied but is not in the client's list, so it is unused.
