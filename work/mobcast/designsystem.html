06 - Motion
Motion

Two easing curves. --ease on 90% of everything. --spring only for bounce CTAs and magnetic interactions. Hover cards to preview.

--ease · Primary
cubic-bezier(.16, 1, .3, 1)
All hover transitions, scroll reveals, card lifts, nav, modals. Expo-out: fast start, smooth deceleration.
--spring · Bounce
cubic-bezier(.34, 1.56, .64, 1)
CTA buttons only (.bw:hover, .bfv:hover), magnetic elements, logo hover. Overshoots then snaps back.

15 - Scroll Reveals
Scroll Reveal Patterns

Three reveal patterns. .sr is standard fadeup. .cinema-enter is deeper lift (48px). .headline-line/.line-inner is the split-line text wipe. JS adds .in or .visible class on IntersectionObserver.

/* Standard scroll reveal - add .sr to elements, JS adds .in */ .sr { opacity:0; transform:translateY(26px); transition:opacity .65s var(--ease), transform .65s var(--ease); } .sr.in { opacity:1; transform:none; } .d1{ transition-delay:.08s; } .d2{ transition-delay:.16s; } .d3{ transition-delay:.24s; } /* Cinema entrance - deeper lift, slower */ .cinema-enter { opacity:0; transform:translateY(48px); transition:opacity .9s cubic-bezier(.16,1,.3,1), transform .9s cubic-bezier(.16,1,.3,1); } .cinema-enter.visible { opacity:1; transform:none; } /* Split headline wipe (Bricolage headings only) */ .headline-line { overflow:hidden; display:block; } .line-inner { display:block; transform:translateY(105%); transition:transform 1s cubic-bezier(.16,1,.3,1); } .line-inner.visible { transform:translateY(0); }
